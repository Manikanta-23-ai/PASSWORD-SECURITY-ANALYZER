# 🔐 Password Security Analyzer

A lightweight Python-based password security analyzer that evaluates password strength using multiple security criteria and provides actionable feedback.

## 📌 Overview

The Password Security Analyzer is a beginner-friendly cybersecurity project built with Python.

It analyzes a password based on:

- Password length
- Lowercase letters
- Uppercase letters
- Numbers
- Special characters

The analyzer calculates a security score and classifies the password as **Weak, Moderate, Strong, or Very Strong**.

> ⚠️ **Security Notice:** Do not enter real passwords into this program. Use sample or dummy passwords for testing.

## ✨ Features

- 🔍 Password strength analysis
- 📊 Security score calculation
- 🔠 Uppercase/lowercase character detection
- 🔢 Number detection
- 🔣 Special character detection
- 📏 Password length validation
- 💡 Security recommendations
- 🐍 Built entirely with Python
- ⚡ Lightweight and easy to run

## 🛠️ Technologies Used

- Python 3
- Regular Expressions (`re`)
- Command Line Interface (CLI)
